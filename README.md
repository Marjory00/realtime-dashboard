## 🌟 Purpose of the Project

The primary purpose of this project is to build a full-stack, real-time data visualization platform that demonstrates proficiency in:
1.  **Backend Data Engineering (Python/Flask):** Ingesting, processing, and aggregating raw data into meaningful metrics, and serving this data efficiently via RESTful APIs.
2.  **Frontend Data Visualization (React/Chart.js):** Creating an interactive, responsive user interface with dynamic charts, filters, and real-time updates to provide actionable insights.
3.  **Monorepo Development:** Managing a decoupled but integrated backend and frontend application.

## 📈 Case Study: Global E-Commerce Sales Performance

**Scenario:** An international e-commerce company needs a dashboard to monitor its sales performance across different product categories and geographical regions in near real-time.

**Data Source (Simulated):** A stream of simulated sales transaction data (Product ID, Category, Region, Sales Amount, Timestamp).

**Key Metrics Visualized:**
1.  **Total Sales Trend:** Daily or hourly sales volume to identify peaks and dips.
2.  **Sales by Category:** A breakdown of revenue generated by the top 'N' product categories (e.g., Electronics, Apparel, Home Goods).
3.  **Regional Performance:** Sales aggregated by the top 'M' operating regions.

**Dashboard Features:**
* **Time Filter:** Users can select a time range (e.g., Last 7 Days, Last 24 Hours).
* **Date Range Selector:** Custom start and end dates can be applied for historical analysis.
* **Data Export:** A button to export the current filtered data to a CSV file.
* **Dynamic Updates:** The charts refresh periodically to reflect new data ingestion.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Node.js and npm (or yarn)
* Git
* PowerShell / Command Prompt

### 1. Backend Setup (Python/Flask)

1.  Navigate to the backend directory:
    ```powershell
    cd realtime-dashboard/backend
    ```
2.  Create a Python virtual environment and activate it:
    ```bash
    python -m venv venv
    .\venv\Scripts\Activate.ps1  # For PowerShell
    # or source venv/bin/activate # For Linux/macOS
    ```
3.  Install the required packages:
    ```powershell
    pip install -r requirements.txt
    ```
4.  Run the Flask API server:
    ```powershell
    python app.py
    ```
    The API will be available at `http://127.0.0.1:5000/`.

### 2. Frontend Setup (React)

1.  Navigate to the frontend directory:
    ```powershell
    cd realtime-dashboard/frontend
    ```
2.  Install dependencies:
    ```powershell
    npm install
    ```
3.  Start the React development server:
    ```powershell
    npm start
    ```
    The dashboard will open in your browser, typically at `http://localhost:3000/`.
